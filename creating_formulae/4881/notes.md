### On a new workbook type in the text and numbers in the same cells as shown below:
> List of MPs
> You will need to change the column widths.
### In cell D2 create a formula using the following information:
> Total Staff Costs  =  Hourrs Worked  *  8.75
> Copy the formula down the column to work out the other Total Staff Costs.

### In cell F2 create a formula using the following information:
> Govt. Allowance  =  1000 * No. staff
> Copy the formula down the column to work out the other Govt. Allowance figures.

### In cell G2 create a formula using the following information:
> Credit/Debit  =  Govt. Allowance - Total Staff Costs - Office Rent
> You will need to think if you need to include any brackets in this formula (BODMAS!).

### In cell B8, create a formula that will add together all the number of staff.
> There is a special button on the toolbar for totals.
> Copy the total formula across the row to calculate the other totals.

### Save the file with the name MP Office Costs.
