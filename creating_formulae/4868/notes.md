### On a new workbook, type in the text and numbers in the same cells as shown below:
> Weight loss statistics
> You will need to change the column widths.

### In cell E2 create a formula using the following information:

> Weekly Loss (kg)  =  (Current - Target) / Weeks

### Copy the formula down the column to work out the other weekly losses in kilograms.

> In cell F2 create a formula using the following information:

> Weekly Loss (lb)  =  Weekly Loss (kg) * 2.2

> Copy the formula down the column to work out the other weekly losses in pounds.

### In cell B6, create a formula that will add together all of the current weights.

> There is a special button on the toolbar for totals.

> Copy the total formula across the row to calculate the other column totals.

### Save the file with the name Healthy Eating.
