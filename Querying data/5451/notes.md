# [Use Power Query to pivot a column in a table of concert tours.](https://www.wiseowl.co.uk/excel/exercises/standard/query-data/5451/)

Create a new Excel workbook and save it as Pivoting Music.xlsx.

Create a query to import the Tours worksheet from the Tour Continents.xlsx file from the folder shown a the top of this exercise.

Load the query into a table in a new worksheet.

An Excel table showing the results of a query created in Power Query
The continent name appears multiple times for different artists and tours.

Edit the query and apply a pivot transform to create a new column for each continent name, using Count_of_shows as the aggregate column.

Close and load the changes to the query.

An Excel table populated with the result of a Power Query query
Each tour should now occupy a single row in the table.

Save and close the workbook.
