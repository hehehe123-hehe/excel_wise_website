Choose to import data from the BPI 2026 Yearbook.pdf file from the folder shown at the top of this exercise.

Select Table038 (Page 14) and load it into a table on a new worksheet.

Imoprting a table from a PDF document in Power Query
The table shows the market value of different types of entertainment in millions of pounds.

We'd like to convert the table so that each year appears on a separate row and each type of entertainment appears in a separate column.

A table imported into Excel from a PDF file using Power Query
Currently, the rows and columns are the wrong way around.

Edit the query and use the Transpose transform to switch the rows and columns.

A transposed table in Power Query for Excel
The rows and columns are switched.

Convert the first row of data to column headers and rename the first column to Year.

A transposed and tidied table in a Power Query query
The data looks more usable now.

Close and apply the changes to the query then save and close the workbook.
