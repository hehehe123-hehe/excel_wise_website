# Excel Practice — Wise Owl Exercises

Personal practice log for working through the free Excel exercises published by [Wise Owl Training](https://www.wiseowl.co.uk/excel/exercises/standard/). The site offers 128 standard Excel exercises across 31 topics, ranging from basic formulas to pivot tables, Power Query, and financial modelling.

> Exercises and source files belong to Wise Owl Training. This repository only contains my own worked solutions and notes — no original exercise files or instructions are redistributed here.

## Why this repo

Documenting hands-on practice with Excel functions and features relevant to data analyst and reporting roles — formulas, lookups, pivot tables, and Power Query — with a focus on techniques that come up often in real analysis work.

## Skills covered

- Formula fundamentals: absolute/relative references, range names, nested IFs
- Lookups: VLOOKUP, HLOOKUP, XLOOKUP, INDEX/MATCH
- Data tools: Tables, sorting/filtering, data validation, conditional formatting
- Spill/dynamic array functions: UNIQUE, SORT, FILTER
- Pivot tables and pivot charts, including slicers and calculated fields
- Charts: standard, combination, scatter with trendlines, sparklines
- Financial modelling: NPV, IRR, scenarios, data tables, cashflow calculations
- Power Query: importing, transforming, appending, and cleaning data sources
